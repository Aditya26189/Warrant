# Evaluated input language and auxiliary instructions

26 October 2026. Applying the locked English-evidence rule before the next
judgments; no new language criterion or English-only-test requirement is added.

The approved rule requires primary method/dataset/source-construction support
for an English-text evaluation setting. Corpus/example-based indirect evidence
needs explicit evaluation linkage and limitations. It does not require every
item or held-out record to be English, or a language-specific results table.

An English detector question, system instruction, parser name, evaluator prompt,
paper exposition or task-neutral mask alone does not establish the language of
the prompt/document being classified. Such instructions may accompany text in
other languages. Record this instruction language as a supported method fact;
retain the input-language question unless other primary evidence resolves it.

Actual English injected templates/input examples explicitly linked to evaluated
construction can establish an English component with disclosed slot/source/test
limitations. A multilingual encoder or an unlinked illustration cannot. Apply
this distinction to a qualifying experiment in its selected edition, rather than
borrowing English evidence from a different response-dependent arm.

The previous positive W0029/W0035 bindings established English auxiliary detector
instructions only. New before-row-bound judgments will return their language
criterion to UNCLEAR while preserving the independently supported input-task,
binary and timing facts. Historical proposals and receipts remain unchanged.
The language inference correction is exposed-custodian self-review, not a fresh
independent review or a reason to exclude these papers. Targeted source requests
must ask only for the missing input-evaluation linkage, without outcomes.
