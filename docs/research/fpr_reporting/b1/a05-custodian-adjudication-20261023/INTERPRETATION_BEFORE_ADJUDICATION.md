# Interpretation recorded before the A05 scientific pass

23 October 2026. These are applications of the locked criteria, not new
eligibility rules. A05 changes the responsible adjudicator and disclosure only.

* Timing concerns the protected target answer. An evaluated classifier whose
  inputs are prompt text or prefill activations can make its decision before
  that answer. An offline evaluation need not demonstrate an actual downstream
  deployment. A separate detector's generated verdict is not the protected
  answer. A classifier that needs the protected answer fails this timing test;
  other separately evaluated input baselines must still be considered.
* A binary decision in an algorithm is not by itself a binary input evaluation.
  The methods must connect the decision to original clean/injected input
  evaluation units. An end-to-end task/attack evaluation alone is insufficient.
* Actual evaluated English input construction supports an English component.
  Mixed-language evaluation is allowed. Dataset names, encoder capability and
  English paper prose alone do not establish language. Neither an English-only
  test split nor complete language proportions are required by the locked rule.
* Bounded evidence describes its experiment. A post-answer evaluator or a
  nonqualifying proposed method does not establish the absence of a qualifying
  secondary baseline elsewhere. Missing evidence stays UNCLEAR. Whole-work
  exclusions require an explicit scope ground, an applicable locked sentinel,
  or another established disqualifying requirement.
* Prefer the publicly available version of record by the cutoff, then accepted
  version, then latest eligible preprint. Registration creation/deposit/indexing
  times do not prove public availability. Month precision is preserved. Source
  body identity, exact revision, publication date and access are separate facts.
  Method evidence is not transferred between versions without source support.
* Keep the locked renamed-work and distinct-work decisions. A paper reused as
  one thesis chapter does not prove whole-document identity; unresolved study
  overlap must be disclosed before any uniform draw.

Every new judgment is attributed to the exposed custodian, informed by the two
preserved returns. Provider request/availability flags are routing information,
not scientific labels. No outcomes, counts or assurance claims are adjudicated.
The deliverable is a complete frame proposal with uncertainties, not permission
to select papers or start B2.
