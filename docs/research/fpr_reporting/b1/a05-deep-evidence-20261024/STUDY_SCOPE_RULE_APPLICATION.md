# Affirmative study scope versus missing implementation detail

25 October 2026. Application of the locked input-injection domain criterion,
recorded before using the new explicitly checked study-scope statements.

A source can affirmatively delimit the original evaluation to image fusion and
vision tasks, or to content moderation and personal-information interactions.
That declared whole-study task/unit scope is scientifically different from a
missing paragraph about one arm. When independently checked against the main
and relevant appendix task design, it can establish that the evaluated task is
outside the pilot domain. Unread within-family model settings or example pixels
do not automatically create an unidentified new prompt-injection experiment.

Use this ground only with an approved, source-linked whole-study task-scope
statement and an explicit failed input-injection-task judgment. Keep unresolved
implementation details and partial inventory flags unchanged. Do not claim the
unseen supplementary material was read, infer absence from a title or one
nonqualifying arm, require outcome values, or treat missing language/statistical
reporting as exclusion. A genuinely possible additional task family remains
material and UNCLEAR until resolved.

This adds no eligibility criterion and relaxes none. It prevents an accidental
requirement to reconstruct every irrelevant implementation parameter before
applying an already established task boundary. The ordinary complete-method
inventory and explicit nonempirical-design grounds remain separate.
