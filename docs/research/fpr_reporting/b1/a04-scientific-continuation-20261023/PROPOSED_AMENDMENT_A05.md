## The exact choice

eligibility adjudication" and requires a completed independent eligibility frame
before another B1 approval. The user has asked the custodian to continue using
its own understanding. Rather than silently interpret that general instruction
as revoking the scientific safeguard, this draft specifies the actual change.

If explicitly approved, the original exposed custodian may finish source-linked
scientific eligibility adjudication and reconciliation of the frozen 372 works,
using the restricted evidence and the preserved independent B return. The final
eligibility layer will be **reviewer-informed custodian adjudication**, not a

independent first pass remains preserved; it is not rewritten or upgraded.

This relaxes A04's authorship/completion safeguard for a feasibility-frame
proposal. It does not erase the earlier A03 exposure. It is a methodological
change with a real limitation, not an administrative correction.
