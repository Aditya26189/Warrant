## Portable-code review

The exporter reads identified original payloads, checks original byte hashes and sizes, validates pinned URLs and complete listings, re-normalizes original and projected trial observations, and compares original/projected native reconciliation. It does not import final scores, cohort decisions or pair labels as scientific inputs. It retains original hashes, transformation identity and derived hashes.

The reader checks the exact payload set, compressed and expanded size limits, hashes, row shapes, allowed content, source URLs, complete hierarchy and trial coverage. Calculation re-normalizes observations and reuses frozen native/identity/bounds helpers. Numerical comparison covers ten scientific tables, selected scientific summary fields and the complete post hoc summary. Its sole diagnostic-column exclusion, `raw_ledger_shards`, is an archival file locator. Numerical scalar spellings can differ while their exact rational values agree; identifiers remain exact strings.

No hardcoded external-cache fallback was found. The reproduction command obtains the committed reviewed bundle, copies it into an empty destination, verifies it and regenerates outputs. During copy/loading/calculation/comparison/report generation, Python audit hooks reject access under explicitly forbidden roots and socket creation is disabled. This guards against accidental Python cache use; it is not an operating-system security sandbox or independent raw-source verification.

Pinned dataset metadata and README actually declare Apache-2.0. The closeout includes attribution, modification notice and upstream license texts rather than assigning Warrant's code license to source observations. Raw logs, transcripts, exception messages/traces, environment values and agent kwargs are omitted. Opaque hashes attest those omitted semantics; the bundle must not be described as independently verifying them.
